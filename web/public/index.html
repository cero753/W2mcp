Or generate from the command line

      
# from a docs URL (LLM reads the HTML)
npx tsx src/cli.ts https://your-api.com/docs --out ./out/myapi --render

# from an OpenAPI / Swagger spec (JSON or YAML — no LLM)
npx tsx src/import-cli.ts https://your-api.com/openapi.json --out ./out/myapi

# verify it against the live API, then host it
npx tsx src/verify-cli.ts ./out/myapi
npx tsx src/gateway-cli.ts        # serves every server in registry.json

    

  


  
  

    
⌘ Run w2mcp in your terminalthe whole product from a shell — no browser, no Claude Code

    

      
1 · install
npm i -g w2mcp   # or run any command with: npx w2mcp …

      
2 · turn any API into an MCP server
w2mcp new https://your-api.com/docs
# HTML docs, OpenAPI or Swagger — all work

      
3 · list & call its tools, live
w2mcp tools --dir ./out/your-api
w2mcp call  --dir ./out/your-api <tool> key=value

      
4 · one agent, every API (the hub)
w2mcp ask "what's the price of bitcoin?" --hub

      
5 · keep it fresh — drift maintenance
w2mcp drift ./out/your-api        # detect API changes
w2mcp drift ./out/your-api --fix  # auto-regenerate

      
6 · host it for your whole fleet
w2mcp gateway   # serves every server in registry.json
